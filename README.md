# Simple Website PHP Utils

Collection of reusable PHP utility functions created for web projects.

## About

This repository contains utility functions developed across different projects, focused on:

- String manipulation
- Data validation
- Array helpers
- Data handling
- Formatting functions
- Integrations and automations
- General-purpose utilities

The goal is to centralize reusable code and improve maintenance, consistency, and development speed across projects.

---

## Structure

```bash
/functions
    string.php
    array.php
    validation.php
    format.php
```

---

## Usage Example

```php
require_once 'functions/string.php';

echo slugify('Olá Mundo');
// ola-mundo
```
